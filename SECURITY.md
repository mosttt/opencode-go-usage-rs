# Security Policy

## Supported versions

Only the latest published release receives security fixes. Please upgrade before reporting an issue that may already have been corrected.

## Reporting a vulnerability

Please use the repository's private vulnerability reporting page instead of a public issue:

<https://github.com/mosttt/opencode-go-usage-rs/security/advisories/new>

If GitHub does not offer the private report form to your account, open a public issue containing only a request for a private contact channel. Do not disclose technical details until the maintainer provides one.

Do not include a real OpenCode Cookie, `config.json`, panel key, workspace identifier, email address, or captured account page. Replace all sensitive values with synthetic placeholders and describe the minimum steps needed to reproduce the problem.

Public issues are appropriate for non-sensitive bugs and feature requests only.
